# To-Do App Java
Eine konsolenbasierte Java-To-Do-App zum Erstellen, Anzeigen, Bearbeiten und Löschen von Tasks.

# Funktionen

- Aufgaben erstellen
- Alle Aufgaben anzeigen
- Aufgaben bearbeiten
- Aufgaben löschen
- Priorität einer Aufgabe festlegen
- Aufgaben als erledigt markieren

# Projektstruktur

Das Projekt besteht aus 3 Hauptklassen:

- `Main` – enthält das Konsolenmenü und verarbeitet die Benutzereingaben.
- `Task` – repräsentiert eine einzelne Aufgabe mit ihren Eigenschaften wie Priorität und Status.
- `TaskService` – verwaltet die Aufgaben und stellt die Funktionen zum Erstellen, Anzeigen, Bearbeiten und Löschen bereit.
